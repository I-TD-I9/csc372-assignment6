# csc372-assignment6

Jokebook API built with Node.js, Express, and PostgreSQL

## Setup

1. Set `DATABASE_URL` in a `.env` file.
2. Run `npm install`.
3. Run `node server.js`.

## API Endpoints

- `GET /jokebook/categories`
- `GET /jokebook/category/:category`
- `GET /jokebook/random`
- `POST /jokebook/add`
